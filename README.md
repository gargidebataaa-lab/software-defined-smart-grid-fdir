# Software-Defined Smart Grid FDIR

## Project Overview
This project simulates Fault Detection, Isolation and Restoration (FDIR) in a reconfigurable electrical distribution network using Python.

## Objectives
- Simulate normal grid operation, feeder outages and overcurrent scenarios.
- Model relay operation and circuit-breaker tripping.
- Evaluate alternate restoration paths using power-flow results and equipment-loading limits.
- Study the impact of solar PV generation and battery energy storage.
- Visualize simulation results through a dashboard.

## Technologies Used
- Python
- Pandapower
- NetworkX
- Streamlit
- Pandas, NumPy and Matplotlib

## How It Works
The project models an electrical distribution network, calculates electrical parameters, simulates selected fault scenarios, and evaluates possible restoration paths. Network topology is assessed using NetworkX, while Pandapower performs power-flow calculations.

## Important Note
This is a simulation-based academic project. Its results are calculated model outputs, not measurements from a physical electrical grid.
